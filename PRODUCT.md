# Generalist Product

Generalist is an Effect-native framework for running agents inside an application. It gives developers one composable model for prompts, tools, model providers, memory, skills, streaming, and optional durable execution.

Generalist is for teams that want typed agent behavior built from Effect services and layers. Applications own their models, tools, storage configuration, interfaces, and deployment.

Generalist stays provider-neutral. `generalist` runs process-local agents; `generalist/runtime` adds durable execution, addressability, replay, and recovery without changing the agent model.

Generalist is not a hosted service, general workflow engine, product UI, identity system, or deployment platform.
