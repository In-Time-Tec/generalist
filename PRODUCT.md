# BatonFX Product

BatonFX is an Effect-native framework for running agents inside an application. It gives developers one composable model for prompts, tools, model providers, memory, skills, and streaming without requiring a durable runtime.

Baton is for teams that want typed agent behavior built from Effect services and layers. Applications own their models, tools, storage, interfaces, and deployment.

Baton stays non-durable and provider-neutral. Relay or another host may add durable execution, addressability, and recovery without changing Baton's agent model.

Baton is not a hosted service, workflow engine, database, product UI, identity system, or durable scheduler.
