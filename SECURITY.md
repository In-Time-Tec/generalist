# Security Policy

Generalist's public exports are experimental and may change in any `0.x` release. Security fixes may therefore include breaking API or data-format changes; release notes describe required migrations.

Report a suspected vulnerability privately through [In Time Tec's contact form](https://www.intimetec.com/contact-us). Identify the Generalist project, request secure disclosure instructions, and do not include exploit details or secrets in the initial form submission. Do not open a public GitHub issue for an undisclosed vulnerability.

Include affected package versions, impact, reproduction steps, and any suggested mitigation once a private channel is established. A maintainer will acknowledge the report, assess affected releases, and coordinate remediation and disclosure with the reporter. No fixed response or remediation timeline is promised.
