# BatonFX Product

BatonFX is an Effect-native framework for running agents inside an application. It gives developers one composable model for prompts, tools, model providers, memory, skills, streaming, and optional durable execution.

Baton is for teams that want typed agent behavior built from Effect services and layers. Applications own their models, tools, storage configuration, interfaces, and deployment.

Baton stays provider-neutral. `@batonfx/core` runs process-local agents; `@batonfx/runtime` adds durable execution, addressability, replay, and recovery without changing the agent model.

Baton is not a hosted service, general workflow engine, product UI, identity system, or deployment platform.
