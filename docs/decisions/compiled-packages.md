# Publish compiled packages

Distribute pure ESM JavaScript and declarations rather than repository TypeScript. Clean Node and Bun consumers must work without workspace protocols, source paths, maps, or Bun's TypeScript loader. One lockstep tarball is built and packed once, verified as the exact release asset, checksummed, attested, attached to the GitHub release, and published unchanged to npm; the host adapters are subpath exports of the same package whose driver dependencies are optional peers, so consumers install only what they import. Generalist does not require a native matrix, CommonJS build, or installer. `generalist/rivet/actors` remains ESM-only even though its raw upstream SDK advertises CommonJS targets; package verification rejects a CommonJS import rather than claiming an unproven path.
