# Getting started

Generalist is an Effect-native TypeScript framework for process-local and durable AI agents.

```sh
bun add generalist effect
```

The [package README](https://github.com/In-Time-Tec/generalist/blob/main/packages/generalist/README.md) owns the first
runnable Agent, package status, and license information. Continue with the [agent loop](features/agent-loop.md) or the
[durable Runtime](features/runtime.md) when you need more detail about those contracts.
