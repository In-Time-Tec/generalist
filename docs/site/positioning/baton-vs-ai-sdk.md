# Baton vs AI SDK

AI SDK is a broad JavaScript AI toolkit with provider APIs and UI-oriented streaming conventions. Baton is narrower: an Effect-native agent loop with typed tools, typed errors, Effect layers, and `Ai.Prompt` / `Ai.Response` as the payload vocabulary.

Choose Baton when your application is already Effect-based or when typed service seams, scoped resources, and typed suspension are central to your architecture.
