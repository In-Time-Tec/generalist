# Memory

Memory is an optional recall/remember seam. The host chooses the key: `{ agent, subject }`. Baton never derives memory subjects from session ids or users.

`@batonfx/memory` ships non-durable working memory, an in-process vector store, semantic recall over Effect AI embeddings, and a combined layer. Durable memory stores remain host adapters.
