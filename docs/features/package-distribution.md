# Package distribution

The public package ships compiled ESM, declarations under `dist/`, and the repository's MIT `LICENSE`. Export maps point only to built files and list types before imports. Effect and third-party dependencies remain external, the tarball uses an allowlist, and the root and package manifests share one exact version.

`bun run package` builds once and packs exactly `generalist` without mutating the source manifest. Bun resolves workspace and catalog protocols. Verification rejects unsafe inventory, missing or inconsistent MIT license metadata, and unresolved protocols; checks exports, exact dependencies, Effect identity, and a size ceiling; then installs the exact tarball in clean Bun-isolated and npm consumers. Wildcard export specifiers are checked by resolving the pattern rather than the literal path.

The packed smoke also imports every documented Worker-safe Generalist subpath from those fresh consumers. It bundles neutral Core, MCP HTTP/OAuth, and Runtime entrypoints separately from OpenRouter with Wrangler and no Node compatibility flags, rejects Node/Bun builtins, stdio, SQL drivers, SQLite, AWS/Bedrock, and provider dependencies in the neutral graph, then loads each emitted bundle with the pinned real `workerd` binary. A successful bundle alone is not conformance: the graph gate proves forbidden modules are absent, while workerd proves the emitted module initializes in the Worker runtime.

The command emits one versioned tarball, `release-evidence.json`, and `SHA256SUMS`. A `v<version>` tag push for the committed version publishes those same three assets as a GitHub release and the exact tarball to npm. A manual run can reconcile one existing immutable tag and commit. Publication verifies registry integrity and never rebuilds downstream artifacts.

Effect is one exact peer. Consumer verification proves one physical Effect installation for the workspace-pinned release candidate.

Minimum consumer profiles are derived from the packed manifest. Core, generic Runtime, and provider-neutral leaves run under fresh Bun and npm/Node installs containing only `effect` and `generalist`; every optional provider, MCP, FoldKit, A2A, AG-UI, and test-host profile installs only its exact peer set and rejects unrelated peers. `generalist/ai/deterministic` is provider-free. SQLite has a separate Bun-only profile with `@effect/sql-sqlite-bun`. The `generalist/pg` and `generalist/mysql` subpaths import `layer` and `RuntimeSchema` under Bun and Node with their driver peers installed. The three `generalist/cloudflare/*` subpaths bundle and initialize under workerd while the `generalist/cloudflare` root remains unexported. `generalist/rivet/actors` imports under Node and Bun with one Effect installation and its declaration dependency present; package smoke also proves CommonJS remains unsupported. Failures identify the profile, runtime, specifier, and missing or unexpected package.
