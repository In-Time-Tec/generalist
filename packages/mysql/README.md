# @tenetkit/mysql

MySQL runtime backend for TenetKit.

```bash
bun add effect@4.0.0-rc.112 tenetkit@0.43.0 @tenetkit/mysql@0.43.0
```

Use `layer(options)` under Node 22+ or Bun 1.4+ to provide the Runtime services. Schema deployment stays separate through `RunSchema.plan`, `RunSchema.check`, and `RunSchema.apply` from this package.
